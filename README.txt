UNITORA
========
A complete front-end conversion website.

FILES
- index.html
- style.css
- script.js

INSTALL
1. Put all 3 files in your existing ultimate-conv folder.
2. Open index.html in your browser.
3. For live currency conversion, the computer needs internet access.
4. The currency converter uses the Frankfurter public exchange-rate API.

GITHUB
After replacing the files:
git add .
git commit -m "Build Unitora converter"
git push

If Git says the remote has newer work:
git pull --rebase origin main
git push

The site includes length, weight, temperature, currency, area, volume,
time, speed and data conversions, plus dark mode, copy result,
responsive layout and live currency rates.
